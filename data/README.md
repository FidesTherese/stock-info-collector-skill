## Purpose

This directory holds the local SQLite database `market-data.sqlite3`. The `collect` command creates it on first use; the `show` command only reads it and never creates it. Git does not track database files. Delete the file only when you intend to discard every stored observation, because the collector never deletes or replaces stored data itself. The parent [README](../README.md) explains how to run the commands.
